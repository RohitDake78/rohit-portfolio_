# Rohit Dake — Portfolio

A clean, responsive portfolio using cream, black, and burnt-orange colors, with a light/dark mode toggle.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
